# This on how to learn languages
**Date**: 24th July 2026

---

Start with a basic language like Python, JavaScript. Either works for your needs. Don't start with a low-level language like Rust, C, C++. You'll encounter on how to do Garbage collectors (except Rust) and suffer through strict compilers.

## Okay.. But what project do I make first?
Easy! Build a simple app. That can be;
- A simple todo app list.
- Build a simple website. Could be your portfolio.
- Simple API provider. Like GitHub, Codeborg, API.
- Lyrics fetcher. Use `lrclib` for getting the lyrics.

Each one of these project can get you the basics on how to program with the language you're using, or the first time you're learning on how to use a language.

## It's too hard...
Don't give up. You have all the resources you need to learn. Searching online, using AI, and asking for help are all great ways to learn. If you're stuck, don't hesitate to ask for help.

Asking to help is not a bad thing. It actually helps you develop your skills and learn faster. How do I know this? I did the same thing myself.

## I think I've got the basics! What next?
Once you've gotten the basics, you should advance furthur. You can take on more complex projects. That being creating your own library, creating your own wrapper, or contributing to open-source projects. This will help grow your skills and knowledge.
